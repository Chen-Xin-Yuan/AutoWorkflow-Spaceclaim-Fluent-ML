# 历史产物

迁移前的旧布局与大文件，**保留原内容作证据，不参与任何自动化流程**。它们不是新 ID 体系的产物：
目录名、文件名、`run.json` 里的 `runId` 都是旧格式（`run-<时间戳>-<短ID>`），数据库里没有对应记录。

| 下级 | 类型 | 作用 |
|---|---|---|
| `spaceclaim/` | 目录 | 迁移前的建模产物（`missile.scdoc`、预览图、一个旧运行目录） |
| `fluent_meshing/` | 目录 | 迁移前的网格与 Fluent workflow 文件（大文件，`fluent_meshing/` 整个子目录被 `.gitignore` 排除） |
| `migration-manifest.json` | 文件 | 旧路径 → 新位置的迁移清单，解释每个文件从哪来 |
| `README.md` | 文件 | 本文件 |

## 与新体系的关系

- **不迁入数据库**：这些产物的几何是 `geometry_id=1` 那套旧临时写法，工况（Ma 0.8、α 3–6°）
  也不在 `C01`–`C30` 网格内，迁进去会污染任务表的完整性假设。
- **不是验收结果**：历史 `PASSED` 字样不能替代新运行的 `review` 记录。要判断某个产物是否算数，
  看 `review` 表里有没有对应的通过记录。
- `gc` 不会碰这里：它只清理 `data_lib/runs/high/<stage>/` 下、由数据库登记过的文件。
