# SpaceClaim 导弹建模需求（prompt_for_sc.md）

> **怎么用**：把这份文件整段当成需求丢给 SpaceClaim / SCDM 建模脚本或 AI，按下面的参数生成一个
> `missile.scdoc`。所有数值都可以改，改完重跑即可，不用改代码。
> 目标环境：SpaceClaim / SCDM 2024 R1（脚本 API `V241`），支持 headless 无人值守运行。
> 单位一律 **米（m）**，表里同时给出我平时说的毫米值。

---

## 0. 一句话目标

**我只输入下面这批参数的具体数值，就自动得到一个 `.scdoc`**，里面同时包含：

1. **导弹本体**（合并后的**单一实体**，名称 `Missile`）；
2. **外壳**（外流场远场边界，名称 `Enclosure`）——必须是"**准备 > 外壳**"那个命令生成的，**不是手画的实体**；
3. **加密区 BOI**（网格细化区域，名称 `BOI`，独立实体）；

外加 CFD 直接能用的**命名选择**、外壳侧面 `wall`、以及**除 missile / BOI / 外壳之外全部物理抑制**。

## 3. 导弹本体：建模要求

1. **弹体**是绕 X 轴的旋转体，剖面在 `(x, r)` 半平面内闭合：弹尖 →（球面钝化弧）→ 锥面 →（交接处倒圆弧）→ 柱面 → 弹底端面 → 沿轴线回到弹尖。
2. **坐标系基准是弹尖**：钝化后球面盖的最前点就是弹尖，弹尾在弹尖 `+L` 处；**钝化与倒角之后总长仍然 = `L`**。
3. **舵面**：两级梯形舵，每级 4 片（十字），沿弹轴圆周阵列 360°，用 `Pattern.CreateCircular`，不要手工复制旋转。
   - 设计梯形定义在**弹体表面**上：那里量到的根弦就是 `C_RW` / `C_RF`，前缘就在 `L_W` / `L_F`；
   - `root_overlap` 只是让舵根沉进弹体的建模手段，沉进去那段沿设计边延伸，所以**可见前缘与可见根弦都精确等于参数值**；
   - 舵面不能有任何顶点正好落在弹体圆柱面上（面重合会让布尔并合不上）。
4. **合并**：所有舵面与弹体 `Combine.Merge` 成**单一实体**（不是多个零件）。
5. **`L_W` / `L_F` 的定义**是字面意思——"舵面可见前缘到弹尖的距离"。钝化、倒角、整体平移都不许改变这个距离。

---

## 4. 外壳：必须是"准备 > 外壳"命令

- 用官方的 **`Enclosure.Create(ISelection, EnclosureOptions)`**（就是菜单"**准备 > 外壳**"那个特性），**不允许自绘旋转实体**。
- 必须显式给：
  1. `EnclosureOptions.Frame = Frame.Create(Point.Create(0,0,0), Direction.DirX)`——命令默认圆柱轴是**全局 Z**，不设就不是沿弹轴；
  2. `Subtract = False`——置真会把导弹从外壳里布尔减掉，远场边界就成了空壳；
  3. `EnclosureCushion = CylinderEnclosureCushion(axisLow, axisHigh, radius)`——命令按"包围盒 + 缓冲"定尺寸：轴向缓冲是包围盒两端的外伸量，径向缓冲要**减去包围盒中心到角点的距离**，参数表里的绝对半径换算成缓冲再传进去。
- 长度 23.83 m（前伸 3.69 + 弹长 3.69 + 后伸 16.45）。
- 命令会把外壳 body 放进一个**新建组件**里，且 body 的 `Name` 是只读的，所以外壳的标识落在**组件名**上（`enclosure_name`，默认 `Enclosure`）。数实体要用 `GetRootPart().GetAllBodies()`，`Part.Bodies` 看不到它。

---

## 5. 加密区 BOI

- 没有对应的官方命令，就用**绕 X 轴的旋转实体**（矩形剖面转 360°），`ExtrudeType.ForceIndependent` 保持**独立实体**（若用 `Add`，BOI 会把里面的导弹吸收掉）。
- 尺寸：半径 0.45、前伸 0.5、后伸 2.5。
- 名字 `BOI`。

---

## 6. 导弹与 BOI 在外壳里的位置

**先整体居中，再往前 4000 mm。外壳不动。**

- 居中：把**导弹 + BOI 这个整体**（BOI 一直把导弹整个包住，所以整体外轮廓就是 BOI）的轴向中位对齐到外壳中点；
- 再叠加 `model_offset = −4.0 m`（负 = 往弹尖方向 = 往前）；
- 计算式：

```text
居中站位(ensemble) = (enclosure_back − enclosure_front)/2 − (boi_back − boi_front)/2
                   = (16.45 − 3.69)/2 − (2.5 − 0.5)/2 = 6.38 − 1.00 = 5.38 m
最终站位           = 5.38 + (−4.0) = 1.38 m        ← 弹尖的绝对 x 坐标
```

- 结果（外壳仍为 `[-3.69, 20.14]`，中点 8.225）：

| 对象 | 轴向范围 (m) | 中点 (m) |
| --- | --- | --- |
| 外壳 | `[-3.69, 20.14]` | 8.225 |
| 加密区 BOI | `[0.88, 7.57]` | 4.225 |
| 导弹 | `[1.38, 5.07]` | 3.225 |

  BOI 前端面到外壳前端面 **4.57 m**，后端面到后端面 **12.57 m**（整体比正中靠前 4.0 m）。
- **不是建完再平移**：站位要直接进剖面与舵面站位，这样解析值和实测值在同一个绝对坐标系里。

## 7. CFD 命名选择（7 组，不能漏面）

| 组名 | 内容 |
| --- | --- |
| `inlet` | 外壳前端盖（弹尖上游） |
| `wall` | 外壳圆柱侧面 |
| `outlet` | 外壳后端盖（弹尾下游） |
| `missile_nose_tip` | 弹尖球面钝化面 |
| `missile_nose` | 圆锥面 |
| `missile_body` | 柱面 + 锥柱交接圆角 + 弹底端面 |
| `missile_fin` | 前/后舵面全部实例 |

要求：**导弹的每一个面都必须落在命名选择里，不许遗漏**。分类要按几何来（回转体面的质心在轴上、舵面全部离轴，先分两族；弹体族按解析面积逐段配对；被舵面裁过的柱面没有解析面积，用排除法取剩下的那一个面）。建完要回读每组的面数与合面积，**4 组导弹选择的面数之和 = 实体总面数**，**面积之和 = 实体自身表面积**。

> `k_tip = 0`（尖头）时 `missile_nose_tip` 没有面，这一组就不建。

## 8. 结构清理与物理抑制

1. **删除阵列残留的空组件**：`Pattern.CreateCircular` 会给每组实例各建一个组件，`Combine.Merge` 之后它们是空的（实测 4 个）。删之前要**逐个确认里面确实没有 body**，删完复核 body 总数不变。
2. **物理抑制**：参与物理计算的只有 `Missile` / `BOI` / `外壳`（外壳 body + 外壳组件，共 4 个对象），结构树里其余东西用 `ViewHelper.SetSuppressForPhysics` 标记抑制（**抑制，不是删除**）。注意 API 只有 setter、没有 getter，所以只能证明"保留集恰好是这 4 个 + 其余每一个调用都成功"。

**验收（不满足就不算成功；进程退出码 0、文件存在都不算证据）**，共 45 项，关键的是：

- 合并后实体数为 **1**；总长 = `L`；展向 = 按相位与片数算出的包围盒；

## 10. 想改参数时怎么改

三类入口等价，改的都是同一批字段（第 2 节那张表）：

```powershell
# 1) 直接命令行覆盖任意字段（负值 = 往前）
node scripts/missile.mjs --model_offset -4.8 --out D:\2_my_sci_train\data_lib\runs

# 2) 预设文件
node scripts/missile.mjs --preset my.json

# 3) 看全部字段与默认值
node scripts/missile.mjs --list
```

约束（超了会被校验挡下，不会静默画错）：`enclosure_radius > 舵尖半径`、`boi_radius < enclosure_radius`、
`enclosure_front + 站位 > 0`、`enclosure_back − 站位 > 0`、BOI 必须嵌在外壳里、`L_W + C_RW ≤ L_F` 等。

> 当前站位 1.38 m 时外壳缓冲是 `(5.07, 15.07)`，都还是正的——继续往前的上限就是当前伸或后伸缓冲被吃到 0 之前。
