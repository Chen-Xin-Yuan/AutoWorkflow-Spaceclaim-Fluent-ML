# 文献、说明和技能导航

- `reference_papers/`：原文献目录，文件保留原样。
- `prompts/`：项目提示词（`prompt_for_sc.md`）；提示词让模型自己写参数 JSON，工作区不保存配套参数文件。
- `skills/`：完整保留的独立 skill 项目；`skills/Fluent_skill/` 含自身 Git。
- `dependency-inventory.json`：依赖清单。
- `task_note.md`：任务笔记。
- `workspace_restructure_report.md`：工作区重构报告。
- `汇报.pptx`：汇报材料（从原 `docs` 迁入）。
- `README.md`：本文件。
- [工作区启动与数据约定](../README.md)
- [SpaceClaim 项目说明](../spaceclaim/README.md)
- [Fluent Meshing 项目说明](../fluent_meshing/README.md)
- 两个代码仓库自身的 `docs` 和 README 配套资源随仓库保留。

`../data_lib/index.json` 可查运行、反馈及历史来源；历史记录标为未重新运行验收。
