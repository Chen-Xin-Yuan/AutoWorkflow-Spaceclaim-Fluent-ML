# Changelog

## 0.1.0

- Added MCP tools for official SpaceClaim API search, document reading, Python command candidates, and geometry recipes.
- Added environment-variable-based CHM discovery through `SCDM_CHM`, `AWP_ROOT261`, or `AWP_ROOT`.
- Added persistent local CHM extraction and metadata indexing.
- Python candidates are API-grounded and marked `inferred`; no local Python knowledge base is used.
